Cara pasang

1

Unduh installer

Klik tombol Download di bagian atas, atau unduh langsung. Ukuran file sekitar 70.5 MB.

2

Jalankan dan instal

Buka file Winnook-Setup di folder Downloads lalu ikuti petunjuk instalasi. Kalau Windows menampilkan peringatan, klik More info lalu Run anyway.

3

Mulai pakai

Jalankan Winnook. Notch akan muncul di bagian atas layar dan siap dipakai.

Pertanyaan umum

Windows menampilkan peringatan SmartScreen. Aman?

Peringatan itu sering muncul untuk aplikasi baru yang belum bertanda tangan digital. Kalau kamu mengunduhnya dari halaman ini, klik More info lalu Run anyway untuk melanjutkan.

Apakah Winnook gratis?

Ya, Winnook gratis dan dibuat sendiri oleh Rama. Kalau kamu terbantu, kamu bisa mendukung lewat tombol traktir kopi di bawah.

Apakah Winnook berat?

Tidak. Installer-nya cuma 70.5 MB dan Winnook jalan di latar belakang. Versi berikutnya juga akan mengoptimalkan performa lagi supaya tetap ringan dan hemat resource.

Bisa dipakai di macOS atau Linux?

Belum. Winnook dibuat khusus untuk Windows.
